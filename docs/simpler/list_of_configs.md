# List of Configs — Search-Policy Tasks (training + eval)

Reference for the diffusion **search-policy** experiments (`SearchPolicyRoboMonkeyDiffusion`,
BC-only / `pg_lambda=0`, DQC chunk verifier baked) across SIMPLER WidowX tasks.

**Key architectural fact:** there is **no per-task config file**. One shared Hydra config +
one shared eval harness are specialized per task by **parameters** (dataset, MUSE embedding,
`TASK` sim-env id). Training is **offline BC** (no simulator); the **simulator only exists at
eval**, selected by the `TASK` env var.

## 2. TRAINING

**Conda env:** `dqc_jax` (only env with both JAX — DQC critic — and torch — policy).
**Simulator:** none — pure offline BC on the zarr dataset (no `env_runner`/`make_env`).

### Shared Hydra config
`diffusion_policy/diffusion_policy/config/robomonkey_eggplant_search_dqc.yaml` — used verbatim by
**every** task; task specifics come from `--export` overrides (below).

Baked policy/training values:
- `horizon: 8`, `n_obs_steps: 1`, `n_action_steps: 4` (predict 8, execute 4), `max_actions: 16`
- verifier: `DQCVerifier`, `critic_type: chunk`, `q_agg: min`, `score_full_horizon: True`
- optimizer: AdamW, `lr: 1e-4`, betas `[0.95, 0.999]`, weight_decay `1e-6`
- `batch_size: 256`, `checkpoint_every: 1000`, `resume: True`

### LR schedule (all runs, step-based)
polynomial, peak **1e-4**, warmup **500** steps, decay over **10 000** steps to `lr_end` **1e-5**,
`power` 1.0 → constant 1e-5 after step 10k. (Set via sbatch env `LR_*`.)

### DQC critic (baked verifier)
`/gscratch/robotics/harine/dqc_checkpoint/sd000s_137913.0.20260605_163017`, `params_100000`
(`DQC_RESTORE_EPOCH=100000`). Base critic, task-agnostic — language-conditioned via the MUSE
embedding, so the same critic serves all tasks.

### Launchers
- **stack/spoon (6 runs):** `scriptsv2/train_search/launch_multitask_search_trainings.sh`
  — sets per-task `DATASET_DIR`, `TEXT_EMB`, `INSTRUCTION`; `PG_LAMBDA=0`,
  `MAX_GRADIENT_STEPS=100000`, `NUM_EPOCHS=60000` (25-ep sets are ~2 steps/epoch, so epochs must
  be high enough that the step cap binds), `NUM_WORKERS=2`, weirdlab `gpu-l40s` 1 GPU / 6 CPU / 96G.
- **underlying sbatch:** `scriptsv2/train_search/train_search_pg.sbatch` (env-parameterized:
  `CONFIG, PG_LAMBDA, CRITIC_DIR, RESTORE_EPOCH, DATASET_DIR, TEXT_EMB, INSTRUCTION,
  MAX_GRADIENT_STEPS, NUM_EPOCHS, NUM_WORKERS, RUN_NAME, LOG_PROJECT, OUT_ROOT`).

### Output dirs + run names
- **stack/spoon:** `OUT_ROOT=/gscratch/robotics/harine/RoboMonkey_data/train/rmse_multitask`
  run names `diff_search_rmse_{stack,spoon}_{sub100,sub50,sub25}_diverse`
- **eggplant:** `.../train/rmse_filtered/diff_search_rmse_{sub100,sub50,sub25}_diverse_data`
- checkpoints: `<OUT_ROOT>/<run>/checkpoints/step_*.ckpt` (+ `latest.ckpt`)
- **per-run resolved config (task specifics frozen):**
  `<OUT_ROOT>/<run>/.hydra/config.yaml` (full merged config) and `.hydra/overrides.yaml`
  (just the CLI overrides).
  e.g. `/gscratch/robotics/harine/RoboMonkey_data/train/rmse_multitask/diff_search_rmse_spoon_sub25_diverse/.hydra/overrides.yaml`
- wandb: project `dqc_search_policy`, entity `l2sml`.

### Per-task `--export` overrides (what makes each run task-specific)
```
CONFIG=robomonkey_eggplant_search_dqc      # shared, same for all
PG_LAMBDA=0                                # BC-only
CRITIC_DIR=/gscratch/robotics/harine/dqc_checkpoint/sd000s_137913.0.20260605_163017
RESTORE_EPOCH=100000
DATASET_DIR=<per-task zarr dir>            # <-- task-specific
TEXT_EMB=scriptsv2/q_fn_eval/task_emb_<task>_use3.npy   # <-- task-specific
INSTRUCTION="<task instruction>"          # <-- task-specific (cosmetic; TEXT_EMB wins)
MAX_GRADIENT_STEPS=100000  NUM_EPOCHS=60000  NUM_WORKERS=2
RUN_NAME=diff_search_rmse_<task>_<sub>_diverse
OUT_ROOT=/gscratch/robotics/harine/RoboMonkey_data/train/rmse_multitask
```

## 3. EVAL (Best-of-N search rollouts)

**Conda env:** `dqc_jax` (the DQC-chunk eval sbatch overrides `eval_search.sh`'s default of
`simpler_env`). **Simulator:** live SIMPLER (SAPIEN/ManiSkill2), selected by `TASK`.

### Scripts (no per-task config)
- launcher: `scriptsv2/eval_search/launch_multitask_ckpt_evals.sh` (sets per-run `TASK`,
  output dir, milestones) → sbatch `scriptsv2/eval_search/eval_search_dqc_chunk.sbatch`
  → `scriptsv2/eval_search/eval_search.sh` → `scriptsv2/eval_search/eval_search.py`
  (`from simpler_env import make as make_env; env = make_env(args.task)`).
- **`TASK` default is eggplant everywhere** — the launcher MUST override it per run
  (`widowx_stack_cube` / `widowx_spoon_on_towel`), else policies are scored in the wrong scene → 0%.

### SIMPLER sim-env definitions (in the SimplerEnv submodule, NOT the RoboMonkey config)
- task-id → sim-env-id registry: `SimplerEnv/simpler_env/__init__.py`
- scenes / instructions / success detectors:
  `SimplerEnv/ManiSkill2_real2sim/mani_skill2_real2sim/envs/custom_scenes/put_on_in_scene.py`

### Verifier at eval
Reconstructed from the **checkpoint's baked `.hydra` config** — so it carries the per-task MUSE
embedding from training automatically (no eval-side override needed once training was correct).

### Eval protocol
`MODE=softmax`, `SOFTMAX_TEMP=1.0`, `N=1 2 4 8 16 32 64`, 50 episodes, seeds 1000–1049,
predict-8 / rollout-4, DQC chunk verifier baked, `DQC_RESTORE_EPOCH=100000`,
`VIZ_Q=1`, `RENDER_Q=1` (10 Q-overlay videos/cell), 2 CPU / 16G, routed to a40/a100.
**Milestones:** `10k 20k 30k 40k 50k 60k 70k 80k 90k 100k`.

### Output dirs + results
- **stack:** `data/eval/stack_cube_search/`  **spoon:** `data/eval/spoon_towel_search/`
  cell dir: `<odir>/<run>_<tag>_chunk8_predh8_roll4_softmax_n<N>_seed1000_ep50/{eval_log.json, search_q/}`
- **eggplant:** `data/eval/search_dqc_chunk/`, `.../filtered_sub{50,25}_diverse_eggplant/`
- **results doc:** `data/eval/search_bon_results.md` (mirror of the canonical
  `data/eval/_verifier_comparison/search_bon_results.md`), auto-generated by
  `scriptsv2/analysis/aggregate_verifier_results.py`.

## 4. Automation

- **login-node crontab** `scriptsv2/eval_search/pg_cron_tick.sh` (`:00`/`:30`): launches ready
  eval cells (`launch_multitask_ckpt_evals.sh`), stages Q-videos, refreshes the results doc.
