## About `archive/`

These are lab-notebook entries, not current documentation: each was true on its date and is
kept because the measurements in it were real. Two things to know before citing one.

`LATEST_SUCCESS_RATES.md` is named "latest" but was last written **2026-08-22**, and covers
neither the LSTM BC arms (trained 2026-09-15), nor PPO, nor SAC. `RESULTS.md` supersedes it.

Several of these docs cite a `SUCCESS_RATES.md` that was **deleted on 2026-08-30** along with
`SUCCESS_RATES_30_100.md` — 6,428 lines between them. References in live code now point at
`docs/reports/SUCCESS_RATES.md`, which `scripts/build_success_rates_doc.py` regenerates; the
references inside `archive/` were deliberately left pointing at the old name, because rewriting
a dated record to cite a document that did not exist when it was written would falsify it.

Most files here are generated. `scripts/build_*_doc.py` writes them, and each now writes into
`archive/` rather than the repo root.
