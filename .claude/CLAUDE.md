# Working rules

- **Investigate thoroughly.** Read the real call path before answering; never infer
  behaviour from a name.
- **Reuse before adding.** Look for an existing structure that already does the job, and ask
  before either reusing it or writing a parallel one.
- **Never decide design alone.** Any choice that changes what gets built goes to the user.
- **Concise documentation.** Report the finding, not the search.
- **Concise comments.** Only where the code cannot say it itself.
- **Colorblind-accessible plots.** No hue-only distinctions -- pair colour with line style,
  marker, or a direct label.
